Rokid Dev Platform · 利用ガイド

グラスアプリを、作って・貯めて・渡すまでの一本道

Rokid Glasses 向けアプリの開発から格納、他環境への受け渡しまで。 Claude Code の CLI と Web UI、どちらから入っても同じ場所（レジストリ）に届きます。実際に翻訳アプリ 1 本を作る流れで見ていきます。

Live Translator
Real-time AR translation
🎤 「翻訳開始」

2つの入り口 — 好きな方でよい

CLI Claude Code から

チャットに指示するだけ。ひな型生成・一覧・入出力を 1 コマンドで。ファイルはそのまま編集対象になります。

向いている人 — 手を動かして実装する開発者。差分やコミットまで一気通貫。

Web UI ブラウザから

一覧・作成フォーム・HUDシミュレータ・要件タブを見ながら操作。インポート/エクスポートもボタンで完結。

向いている人 — 企画・デザイン・レビュー担当。コードを書かず全体像を掴める。

どちらも同じ apps/registry.json を読み書きします。CLI で作ったアプリは UI にも即座に現れ、逆も同じ。混在して使えます。

利用の流れ — 「翻訳アプリ」を例に

0

プラットフォームを起動する

Web UI を使うなら最初に一度だけ。CLI だけで完結するなら不要です。

端末 / Claude Code
bash
# 依存インストール不要（Node標準ライブラリのみ）
$ cd rokid-platform
$ npm run serve      # → http://localhost:4173
1

アプリのひな型を作る

テンプレート（実行場所）を選んで生成。音声コマンドやタグラインをその場で指定できます。

CLI の場合
rokid
$ node cli/rokid.js new "Live Translator" -t cxr-s-ondevice \
      --voice "翻訳開始" --tagline "Real-time AR translation" \
      --pkg com.example.translator
# → apps/live-translator/ に 5ファイル生成 + レジストリ登録
UI の場合 — 「新規作成」タブ → テンプレート選択 → アプリ名・音声コマンド等を入力 → 生成する。作成後すぐ詳細画面へ。
2

中身を実装する

生成物は Android マニフェスト・build.gradle・実装スケルトン・記述子 rokid.app.json。Claude Code でそのまま編集し、実装を書き進めます。

apps/<id>/
apps/live-translator
README.md
build.gradle
rokid.app.json
src/main/AndroidManifest.xml
src/main/java/com/example/translator/HudActivity.java  ← ここに実装
3

HUDシミュレータで見え方を確認

実機がなくても、右目単眼・単色グリーンの見え方を UI 上でプレビュー。名前・タグライン・音声コマンドがレンズに描画されます。

UI の場合 — 「アプリ」タブでアプリを選ぶと、右側のレンズ枠に HUD が表示。単眼・単色前提のレイアウト崩れをここで早期に発見できます。
4

エクスポートして持ち出す

アプリ一式を .rokidapp（依存ゼロの JSON バンドル）1 ファイルに。メンバー共有や別環境への移送に使います。

CLI の場合
rokid
$ node cli/rokid.js export live-translator
# → exports/live-translator.rokidapp
UI の場合 — 詳細画面の エクスポート (.rokidapp) ボタンでそのままダウンロード。
5

別の環境で取り込む

受け取った .rokidapp をインポートすると、フォルダとレジストリを完全再構築。ID が衝突しても自動で採番するので上書き事故がありません。

CLI の場合
rokid
$ node cli/rokid.js import ./live-translator.rokidapp
# → 取り込み完了、そのまま編集・再エクスポート可能
UI の場合 — サイドバーの インポート から .rokidapp を選ぶだけ。取り込んだアプリが即座に一覧へ。
6

APK をビルドして実機へ（ワイヤレス可）

実装が固まったら Gradle で APK を作り、グラス（YodaOS）へ。有線ケーブルは必須ではありません — Wi-Fi/Bluetooth 経由の配信が主流です。

端末 — 📶 Wi-Fi 経由（推奨）
bash
$ ./gradlew assembleDebug            # build/outputs/apk/debug/*.apk
$ adb connect <glasses-ip>:5555     # Wi-Fi 接続（ケーブル不要）
$ adb install -r app-debug.apk       # Rokid Glasses へ
プラットフォーム内蔵の device コマンドでも完結できます — rokid device tcpip（初回のみ）→ rokid device install <id> --target <ip> でビルド済みAPKを Wi-Fi 経由インストール。デフォルトアプリの backup / restore も可能です。

CLI と Web UI の対応表

やりたいことCLI（Claude Code）Web UI
テンプレート/要件を見るrokid templates / spec「開発要件」タブ
アプリを作るrokid new <名> -t <型>「新規作成」フォーム
一覧・詳細を見るrokid list / show <id>「アプリ」タブ + 詳細
見え方を確認ファイルを直接確認HUDシミュレータ
エクスポートrokid export <id>エクスポートボタン
インポートrokid import <file>インポートボタン
削除rokid remove <id>削除ボタン

格納場所 — アプリの実体は rokid-platform/apps/<id>/、一覧は apps/registry.json。 リポジトリにコミットすればチームで共有でき、.rokidapp はリポジトリ外の相手にも 1 ファイルで渡せます。

テンプレートは現在 CXR-S（オンデバイス） / CXR-M（スマホ連携） / Web HUD（試作） の 3 種。CXR-L・UXR(Unity) は今後追加予定です。
